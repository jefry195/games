## ✨ Fitur Unggulan

- 🕹️ **50 Game Lengkap:** Mulai dari game legendaris arcade (*Pac-Man, Flappy Bird, Space Invaders, Tetris, Snake*) hingga game strategi/puzzle (*Catur, 2048, Sudoku, Solitaire, Wordle*).
- 📱 **100% Responsif:** Menyesuaikan ukuran layar smartphone (Android & iOS), tablet, iPad, dan laptop secara presisi.
- ⬅️ **Tombol Navigasi Cerdas:** Setiap game dilengkapi tombol melayang (*floating pill*) **`⬅ Kembali ke Menu`** untuk kembali ke halaman utama kapan saja.
- 🔍 **Portal Pencarian & Filter:** Menu utama dilengkapi fitur pencarian instan (shortcut `/`) dan tombol kategori (*Arcade, Puzzle, Kartu & Papan, Aksi, Mengetik*).
- ⚡ **Tanpa Instalasi / Dependency:** Murni vanilla web technology (HTML, CSS, JS) yang sangat ringan dan cepat dimuat.

## 📖 Deskripsi Game

1. **Candy Crush Game**: Game puzzle mencocokkan tiga permen warna-warni untuk mencetak skor setinggi mungkin. 🍬🍭
2. **Pac-Man Game**: Kendalikan Pac-Man di labirin neon, habiskan semua titik makanan, dan hindari kejaran hantu nakal. 👻
3. **Chess Game (Catur)**: Permainan strategi catur klasik dengan aturan standar pada papan 8×8. ♟️
4. **Doodle Jump Game**: Lompat dari satu pijakan ke pijakan lainnya setinggi mungkin tanpa terjatuh. 🦘
5. **Solitaire Game**: Permainan kartu klasik Klondike. Susun kartu secara berurutan dengan warna selang-seling. 🃏
6. **Sudoku Game**: Isi kotak 9×9 dengan angka 1 sampai 9 tanpa ada angka berulang di baris, kolom, atau sub-kotak. 🧩
7. **Crossy Road Game**: Bantu karakter melompati jalan raya ramai dan sungai berbahaya dalam petualangan tiada henti. 🚦
8. **Rock Paper Scissors**: Permainan adu strategi tangan gunting-batu-kertas klasik melawan komputer. ✂️
9. **Flappy Bird Game**: Terbangkan burung melewati celah pipa hijau dengan ketukan berirama dan raih skor tertinggi. 🐦
10. **2048 Game**: Geser dan gabungkan ubin angka yang sama hingga berhasil membentuk angka 2048. 🔢
11. **Wordle Game**: Tebak kata rahasia dalam 6 kesempatan dengan bantuan petunjuk warna pada setiap tebakan. 📝
12. **Hangman Game**: Tebak kata tersembunyi huruf demi huruf sebelum gambar orang digantung selesai dibuat. 🎩
13. **Tower Blocks Game**: Tumpuk balok setinggi langit dengan ketelitian presisi agar menara tetap seimbang dan tidak roboh. 🏗️
14. **Archery Game (Panahan)**: Uji fokus dan bidikan tepat sasaran dengan busur dan panah ke target lingkaran. 🏹
15. **Tic Tac Toe (XOX)**: Tantang teman atau komputer dalam permainan strategi menempatkan tiga simbol berurutan. ⭕❌
16. **Minesweeper Game**: Gunakan logika dan angka petunjuk untuk membuka semua petak tanpa menginjak ranjau. 💣
17. **Speed Typing Game**: Tingkatkan kecepatan dan akurasi jari mengetik kata-kata bahasa di bawah tekanan waktu. ⌨️
18. **Breakout Game**: Hancurkan seluruh deretan balok bata dengan memantulkan bola menggunakan raket geser. 🧱
19. **Ping Pong Game**: Keseruan tenis meja retro klasik melawan kecerdasan buatan komputer yang tangkas. 🏓
20. **Tetris Game**: Atur dan putar balok aneka bentuk yang jatuh untuk melengkapi baris mendatar penuh. 🕹️
21. **Tilting Maze Game**: Miringkan bidang labirin untuk menggulirkan bola menuju pintu keluar tanpa jatuh ke lubang jebakan. 🌀
22. **Memory Card Game**: Uji kekuatan daya ingat visual Anda dengan menemukan pasangan kartu bergambar sama. 🃏
23. **Type Number Guessing Game**: Tebak angka rahasia yang dipilih komputer berdasarkan petunjuk 'terlalu besar' atau 'terlalu kecil'. 🔢
24. **Snake Game**: Pandu ular memakan apel agar tumbuh panjang, waspada jangan sampai menabrak ekor sendiri atau tembok! 🐍
25. **Connect Four Game**: Jatuhkan koin ke kolom papan dan susun empat koin warnamu dalam satu garis lurus. 🔵🔴
26. **Insect Catch Game**: Uji kecepatan refleks mata dan tangan dengan membasmi serangga nakal yang berhamburan. 🐞
27. **Typing Game 1**: Tantang dirimu mengetik daftar kata secepat mungkin tanpa kesalahan ketik. ⌨️
28. **Dice Roll Simulator**: Simulasi kocok dadu digital 3D dengan visual realistis untuk berbagai keperluan game papan. 🎲
29. **Shape Clicker Game**: Klik berbagai bentuk geometri yang bermunculan secara acak sebelum batas waktu berakhir. 🔷🔶
30. **Typing Game 2**: Uji kemahiran mengetik kata-kata dinamis dalam mode waktu berpacu dengan batas detik. ⚡
31. **Speak Number Guessing Game**: Tebak angka rahasia hanya dengan berbicara ke mikrofon perangkat Anda (Web Speech API). 🗣️🔢
32. **Fruit Slicer Game**: Tebas dan potong buah-buahan segar yang beterbangan layaknya ninja, awas jangan sampai terkena bom! 🍉🔪
33. **Quiz Game**: Asah wawasanmu dengan menjawab aneka soal kuis pilihan ganda dan kumpulkan skor sempurna. 🧠📚
34. **Emoji Catcher Game**: Gerakkan wadah penampung ke kiri dan kanan untuk menangkap emoji gembira yang berjatuhan. 😄🎯
35. **Whack A Mole Game**: Pukul tikus mondok nakal yang menyembul dari lubang tanah secepat kilat sebelum mereka sembunyi. 🕹️
36. **Simon Says Game**: Perhatikan dan hafalkan kombinasi lampu warna-warni, lalu ulangi urutan tombolnya secara tepat. 🎮💡
37. **Sliding Puzzle Game**: Geser kepingan gambar pada petak kosong hingga gambar utuh tersusun rapi kembali. 🧩
38. **Mastermind Game**: Pecahkan sandi kombinasi warna rahasia milik komputer berdasarkan indikator pasak penunjuk. 🎯
39. **Blackjack Game (21)**: Kombinasikan nilai kartu mendekati angka 21 tanpa melebihi batas untuk menaklukkan sang bandar. 🃏
40. **Bubble Shooter Game**: Arahkan meriam gelembung ke kelompok warna senada untuk meletuskan dan membersihkan langit-langit. 🔵
41. **Checkers Game (Dam)**: Permainan dam papan 8×8 klasik. Lompat dan mangsa pion lawan hingga menjadi raja pion. ♟️
42. **Space Invaders Game**: Hancurkan konvoi armada alien luar angkasa sebelum mereka mendarat dan membumihanguskan bumi. 👾
43. **Asteroids Game**: Kendalikan pesawat tempur ruang angkasa, tembak hancur batuan asteroid dan piring terbang musuh. 🚀
44. **Reversi Game (Othello)**: Jepit kepingan milik lawan untuk membalik warnanya menjadi milikmu dan kuasai mayoritas papan. ⚪⚫
45. **Mahjong Solitaire Game**: Temukan dan pasangkan dua balok ubin mahjong bebas yang identik untuk mengosongkan meja. 🀄
46. **Frogger Game**: Bimbing kodok kecil menyeberangi jalan raya padat mobil dan melompat di atas batang kayu sungai. 🐸
47. **Poker Game (5-Card Draw)**: Susun kombinasi kartu terbaik (Pair, Flush, Full House, Royal Flush) melawan bot komputer. 🃏
48. **Battleship Game**: Tentukan posisi armada lautmu dan tebak koordinat lokasi kapal tempur musuh untuk menenggelamkannya. 🚢
49. **Nonogram Game (Picross)**: Isi petak kisi berdasarkan deretan angka petunjuk untuk menyingkap ilustrasi gambar rahasia. 🧩🎨
50. **Lights Out Game**: Matikan seluruh lampu yang menyala dengan memikirkan efek tombol tetangga yang ikut terbalik. 💡

## 💻 Cara Menjalankan di Komputer Lokal (Localhost)

Jika ingin menjalankan secara offline di komputer sendiri:

1. **Clone repository ini:**
   ```bash
   git clone https://github.com/jefry195/games.git
   cd games
   ```

2. **Jalankan local server:**
   - Menggunakan Python:
     ```bash
     python -m http.server 8002
     ```
   - Atau menggunakan Node.js (npx serve):
     ```bash
     npx serve .
     ```

3. **Buka di browser:**
   Akses `http://localhost:8002`
