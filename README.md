## ✨ Fitur Unggulan

- 🐬 **Sentuhan Kearifan Lokal Samarinda:** Mengusung tema kebanggaan Kota Tepian & Sungai Mahakam lengkap dengan maskot **Pesut Mahakam**, ornamen etnik tenun, serta nuansa lokal Kalimantan Timur.
- 🚀 **Game 3D FPS Shooter Baru (`#51 Mahakam FPS Defender`):** Game First-Person Shooter 3D murni berbasis WebGL (Three.js) dengan arena pertahanan Tepian Mahakam, sistem gelombang drone musuh, audio synth, dan kontrol sentuh mobile (virtual joystick & touch look).
- 🏆 **Papan Peringkat Real-Time (Google Sheet & Apps Script):** Dilengkapi integrasi database Google Sheet gratis untuk mencatat dan menampilkan peringkat Top 10 skor tertinggi pemain dari seluruh daerah secara real-time!
- 📱 **100% Responsif di Semua Perangkat:** Mendukung layar sentuh smartphone (Android & iOS), tablet, iPad, dan komputer desktop/laptop.
- ⬅️ **Tombol Navigasi Cerdas:** Setiap game dilengkapi tombol melayang (*floating pill*) **`⬅ Kembali ke Menu`** untuk kembali ke portal utama dengan satu sentuhan.
- 🔍 **Portal Pencarian & Filter:** Menu utama dilengkapi pencarian instan (shortcut keyboard `/`) dan filter kategori (*Aksi & Santai, Arkade Klasik, Teka-Teki & Otak, Papan & Kartu, Kecepatan & Mengetik*).

## 📊 Integrasi Papan Peringkat Google Sheet

Proyek ini telah dilengkapi dengan kode backend **Google Apps Script** dan modul frontend siap pakai:
- File backend: [`google-apps-script/Code.gs`](./google-apps-script/Code.gs)
- Panduan deployment 2 menit: [`google-apps-script/README-GOOGLE-SHEET.md`](./google-apps-script/README-GOOGLE-SHEET.md)
- Konfigurasi URL: [`assets/leaderboard-config.js`](./assets/leaderboard-config.js)

*Jika URL Google Apps Script belum diisi, sistem secara otomatis akan menggunakan LocalStorage browser sebagai fallback sehingga fitur leaderboard tetap bisa langsung dicoba.*

## 💻 Cara Menjalankan di Komputer Lokal (Localhost)

Jika ingin menjalankan secara offline di komputer sendiri:

1. **Clone repository ini:**
   ```bash
   git clone https://github.com/jefry195/games.git
   cd games
   ```

2. **Jalankan local server:**
   - Menggunakan Python:
     ```bash
     python -m http.server 8002
     ```
   - Atau menggunakan Node.js (npx serve):
     ```bash
     npx serve .
     ```

3. **Buka di browser:**
   Akses `http://localhost:8002`
